# Hospital Readmission Risk Analysis

## Project Overview

An end-to-end data analytics portfolio project focused on examining historical hospital encounter data and communicating factors associated with 30-day hospital readmissions.

## Business Objective

Analyze historical hospital encounter data to understand 30-day hospital readmissions, identify patient and encounter characteristics associated with higher readmission rates, and eventually build a dashboard and risk-analysis application.

## Current Project Status

Phase 1 — Project Setup

## Planned Technology Stack

Python, Pandas, SQLite, SQL, Tableau Public, scikit-learn, Streamlit, Git, and GitHub
